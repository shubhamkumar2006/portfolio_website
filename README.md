# Shubham Kumar Portfolio

A modern, high-performance personal portfolio website built with React 19, Vite, Tailwind CSS, Framer Motion, and React Icons. This portfolio highlights full-stack projects, competitive coding milestones, certifications, education, skills, and contact information in a sleek, glassmorphic dark theme.

## Features

- **Modern Glassmorphic Dark Design**: Custom tailored with cyan, violet, and emerald accents.
- **Responsive Layout**: Designed and optimized for desktop, tablet, and mobile displays.
- **Projects Showcase**: Interactive cards featuring impact metrics (concurrency, efficiency, latency reduction), tech stack badges, and GitHub links.
- **DSA & Competitive Coding Badges**: Highlights HackerRank 4-Star C++ and LeetCode 100-Day badges.
- **Interactive Skills Matrix**: Categorized filterable technical skills (Languages, Frontend, Backend, Databases & Caching, DevOps & Tools, Core CS).
- **Direct Resume Access**: Quick download link for Shubham Kumar's official CV PDF.
- **Active Navigation & Smooth Scrolling**: Observer-driven navbar with active state tracking.

## Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React & React Icons

## Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Run the development server

```bash
npm run dev
```

### 3. Build for production

```bash
npm run build
```
